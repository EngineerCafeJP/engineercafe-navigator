# Knowledge Base PDF/テンプレート作成ガイド

**対象**: ナレッジベース管理画面で使用する PDF またはテンプレートの作成方法

---

## 概要

ナレッジベースアップロード機能では、**PDF ファイルからテキストを自動抽出**して知識登録が可能です。

このガイドでは、バックエンドが正しくテキスト抽出できるような PDF やテンプレートの作成方法を説明します。

---

## テンプレートの基本構成

各エントリは以下の構造にしてください：

```text
================================================================================
エントリ 1: [タイトル]
================================================================================

【タイトル】
会議室の予約方法

【内容】
エンジニアカフェの会議室は以下の方法で予約できます：

1. ウェブサイトにアクセス
2. 「会議室予約」ページから希望日時を選択
3. 必要な情報を入力
4. 確認メール受け取り
5. 予約完了

利用可能な会議室：
- 小会議室（1-2名）
- 中会議室（3-5名）
- 大会議室（6-10名）

利用時間：
- 平日：9:00 - 18:00
- 土曜：10:00 - 16:00
- 日曜・祝日：休館

【カテゴリ】
設備

【言語】
ja
```

---

## 各項目の詳細

### 【タイトル】
- **文字数**: 200文字以内
- **例**: 「会議室の予約方法」「Wi-Fi接続手順」「営業時間について」

### 【内容】
- **推奨長さ**: 300-2000文字
- **含める内容**: ステップバイステップ、具体例、注意点、関連情報
- **重要**: 詳しく具体的に記載（LLM が質問に答えるための情報源になります）

### 【カテゴリ】
以下から1つ選択：
- `基本情報`: 営業時間、所在地、連絡先
- `料金`: 会員プラン、日額プラン、割引
- `設備`: 会議室、駐車場、Wi-Fi、その他設備
- `イベント`: 勉強会、セミナー
- `アクセス`: 交通アクセス、道順

### 【言語】
- `ja`: 日本語
- `en`: 英語

## PDF 作成方法

### Markdown テンプレート → PDF 変換

**オンラインツール（推奨）**:
1. Markdown テンプレートをダウンロード
2. Pandoc Online (https://pandoc.org/try/) にアクセス
3. Markdown をペースト
4. 出力形式を PDF に選択
5. PDF をダウンロード

**デスクトップツール**:
- Microsoft Word / Pages: テキストをコピー → Word/Pages に貼付 → PDF保存
- Google Docs: Google Docs で作成 → ファイル → PDF形式でダウンロード
- Pandoc（コマンドライン）: `pandoc template.md -o template.pdf`

---

## テンプレート品質チェック

PDF 作成後、以下をご確認ください：

- [ ] ファイル形式が PDF（.pdf）
- [ ] テキスト選択・コピーが可能（画像スキャンではない）
- [ ] 各エントリが「【タイトル】【内容】【カテゴリ】【言語】」を含む
- [ ] 日本語が正しく表示されている
- [ ] ファイルサイズが 10MB 以下
- [ ] 複数エントリを含む（2個以上推奨）

---

## アップロード手順

1. ブラウザで `/admin/knowledge/upload` にアクセス
2. 作成した PDF をドラッグ&ドロップ
3. カテゴリと言語を選択
4. 「アップロード」をクリック
5. バックエンドが自動的にテキストを抽出して登録

## ベストプラクティス

### 良い例

```text
【タイトル】
会議室の予約方法

【内容】
エンジニアカフェの会議室予約はウェブサイトから簡単にできます。

【予約手順】
1. https://example.com/booking にアクセス
2. 希望日時を選択
3. 会議室を選択（小・中・大から選択）
4. 参加人数と用途を入力
5. メールアドレスを入力
6. 「予約確定」をクリック

【注意事項】
- 当日の予約はお電話でお願いします
- 24時間以内のキャンセルは手数料がかかります
- 外部スペースレンタル時は事前申告が必要です

【カテゴリ】
設備

【言語】
ja
```

### 避けるべき例

```text
【タイトル】
予約

【内容】
予約してください

【カテゴリ】
その他

【言語】
ja
```

## 複数エントリの例

```text
================================================================================
エントリ 1: 会議室の予約方法
================================================================================
【タイトル】会議室の予約方法
【内容】[詳細説明...]
【カテゴリ】設備
【言語】ja

================================================================================
エントリ 2: Wi-Fi接続方法
================================================================================
【タイトル】Wi-Fi接続方法
【内容】[詳細説明...]
【カテゴリ】設備
【言語】ja

================================================================================
エントリ 3: 営業時間について
================================================================================
【タイトル】営業時間について
【内容】[詳細説明...]
【カテゴリ】基本情報
【言語】ja
```

このように、1つのファイルに複数エントリを含めることで、効率的にバルク登録できます。
